  view entry. A view entry describes a row in a view.」有 **getColumnValues**

- `.../basic/H_GETALLENTRIESBYKEY_METHOD_JAVA.html`（Java）→「Finds view entries
  of type document based on their column values within a view」「returns all
  entries whose column values match the keys」。參數 `Vector keys` / `Object key`
  + `boolean exact`(true=精確;false 或省略=**部分比對**成立)。回 `ViewEntryCollection`。
- `.../basic/H_GETVIEW_METHOD_JAVA.html`（Database.getView, Java）→「Finds a view
  **or folder** in a database, given the name or alias」;參數 `String name`
  (case-insensitive);回 `View`(name 或 alias 相符者)。「**do not combine the
  view name and an alias**」。
  ⚠️ **not-found 行為官方頁未明述**(沒寫回 null)→ 文章**不臆測回 null**;改寫
  「getView 沒有 getDatabase 那種 createonfail 空殼;拿到就用,拿不到就 guard」。

## identifier / 行為查核

- `getColumnValues` 在 **ViewEntry**、不是 View(效能角度 identifier 要掛對)。
- `getView` 回「view **or** folder」→ 可能拿到 folder,用 `isFolder()` 區分。
- `getAllEntriesByKey` 回 `ViewEntryCollection`;`exact=false/省略` 走部分比對。
- 跟 java-database 的對照:getDatabase 有 createonfail 空殼、getView **沒有**那招
  (只寫「相符者」)——不把「getView 回 null」講成官方明述。
