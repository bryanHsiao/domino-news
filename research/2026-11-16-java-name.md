## identifier / 行為查核（逐字驗）

- 比對正解:`session.createName(a).getCanonical().equalsIgnoreCase(
  session.createName(b).getCanonical())`——兩邊都正規化成 canonical 再比。
- 只比 common 名:`getCommon()` 兩邊比(但 common 可能撞名,慎用)。
- Abbreviated 在會有歧義時會退回 canonical(例「CN=John B Goode/OU=East」不縮,
  因 East 會被當成 O=)——文章以此當縮寫陷阱的說明。
- OU 最多四層(getOrgUnit1..4);判斷某人是否在某 OU 用這些 getter,別字串 contains。
- RFC 821/822:傳入 `jbg@us.acme.com` 會被當 internet 地址,getAddr821 等解析。
