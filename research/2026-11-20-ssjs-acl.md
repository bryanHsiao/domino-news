# Research trail — ssjs-acl (2026-11-20)

**Topic**: `NotesACL`(SSJS/XPages)—— XPages 兩種權限場景:①**查**目前使用者/某人
的權限做條件渲染(`database.getCurrentAccessLevel()` / `queryAccess(name)` /
`queryAccessRoles(name)`,不必開 ACL 物件);②**改** ACL(admin UI)要 `save`,
而且 web 使用者通常沒 Manager 權限 → 得走 `sessionAsSigner` 提權。插旗
`coversClass: [ACL, ACLEntry]` ＋ `apiLang: ssjs`。Path A,排程 #10(11/20)。

## identifier / 行為查核（逐字驗）

- 查權限做 UI 判斷:`database.getCurrentAccessLevel()` 比常數
  `>= NotesACLEntry.LEVEL_EDITOR`;角色門禁用 `database.queryAccessRoles(name)`
  回的角色清單 —— 比「開 ACL → getEntry → isRoleEnabled」乾淨。
- 改 ACL:同 #9 要 `save`;但 web 使用者多半非 Manager,改 ACL 要用
  `sessionAsSigner.getDatabase(...)` 取庫(以設計元件簽署者身分、需該簽署者有
  Manager 權)。見 xpages-sessionassigner。
- SSJS getter 形式(getCurrentAccessLevel/getACL/queryAccess)皆可。
