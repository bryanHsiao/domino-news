## 官方 HCL 14.5.1（WebFetch 逐字驗;Java notebook 污染走 WebFetch）

- `.../basic/H_NOTESLOG_CLASS_JAVA.html`(class)→「Enables you to record actions
  and errors that take place during a program's execution.」可寫 Domino db / mail
  memo / 本地檔 / agent log。建立:`createLog` in Session(名稱=ProgramName)。open*
  (記錄前必須先 open):openNotesLog(指定 db)、openMailLog(新 memo,close 或物件
  刪除時寄出)、openFileLog(檔案,**server 上呼叫會回 error**)、openAgentLog(「Opens
  the agent log for the current agent.」)。記錄:logAction「Records an action in a
  log.」、logError「Records an error in a log.」、logEvent(送 Domino event 到網路)、
  close。**「actions and errors are not logged automatically. You must call logAction
  and logError explicitly.」** 屬性:IsLogActions / IsLogErrors(rw 開關)、
  IsOverwriteFile(rw,只對 file log 有效:覆蓋 vs append)、ProgramName(rw,=createLog
  名)、NumActions / NumErrors(ro)、Parent(ro)。
- `.../basic/H_OPENAGENTLOG_METHOD_JAVA.html`(openAgentLog,14.5.1 非 404)→「Opens
  the agent log for the current agent.」非 agent 執行會失敗、「does not work for
  remote (IIOP) operations.」
- `.../basic/H_NOTESSESSION_CLASS_JAVA.html`(Session,核心,createLog 在此)。

## identifier / 行為查核（逐字驗）

- 建立:`session.createLog("name")`;name 進 ProgramName。
- 先 open 一個去處再 log:四個 open* 對四個目的地。
- openFileLog 在 server 上會 error(server agent 別用);openAgentLog 非 agent/遠端會失敗。
- logAction/logError 不自動,要手動;NumActions/NumErrors 計數。
- 屬性是 **Is 前綴**(IsLogActions,非 LogActions);IsOverwriteFile 只影響 file log。
- openMailLog 的 memo 在 close() 時才寄 → 記得 close。
- Log 是後端 handle,用完 recycle。
