Domino 14.5.1 的第一個 Fix Pack 在 [2026-07-16 上線](https://developer.ds.hcl-software.com/t/hcl-notes-domino-14-5-1-fp1-is-now-live/172656)，官方一句「建議所有客戶安裝」帶過，沒什麼聲響。但它值得你花五分鐘看一眼——尤其如果你正在 14.5.1 上被某些怪問題咬，或者在等 Domino IQ 的 RAG 能接遠端模型。

Fix Pack 的本質是累積修正，不是新版本；這一包裡真正的新功能只有一個，其餘大多是把 14.5.1 自己弄壞的東西修回去。以下挑對開發者與管理者最有感的講。

---

## 重點摘要

- **RAG 多了 Remote 模式**：LLM 與 embedding 模型可以跑在遠端 endpoint，向量資料庫仍固定在本機 Domino IQ server。想用 Domino IQ、又不想每台都插 GPU 的，這是關鍵一步。
- **約 49 個修正，不少是 14.5.1 自己的 regression**：升上 14.5.1 後遇到的新怪象，FP1 很可能已經修掉。
- **JVM 更新到 Semeru `jdk-21.0.11+10`（時區資料 2026b）**：跟日期、時區處理有關的都受惠。
- **2 個安全修正**：修復 OIDC 串接式 Identity Provider 設定，新增 `OIDC_LOGIN_COOKIE_UNLIMITED_DURATION` 控制登入 cookie 效期。
- **幾個 notes.ini 小開關**：tabbed table 的顏色行為調回 14.5.1 之前、MIME 郵件的內嵌瀏覽器從 IE 換成 Edge。

---

## 唯一的真新功能：RAG 終於能接遠端模型

FP1 之前，Domino IQ 的 RAG 只能整條跑在本機——推論引擎、embedding、向量資料庫全綁在同一台 Domino IQ server 上，那台就得有 GPU。[官方的 FP1 說明](https://help.hcl-software.com/domino/14.5.1/admin/whats_new_in_1451FP1.html)寫得很直接：RAG 現在同時支援 **Local 與 Remote** 兩種模式。差別在於，LLM 與 embedding 模型可以搬到遠端 endpoint，**向量資料庫則永遠留在本機** Domino IQ server。

這一步對想導入 Domino IQ 的人很關鍵：你不必再讓每一台要用 RAG 的 server 都插 GPU，可以把幾台重機集中在遠端、其餘接過去。（順帶一提，站上那篇 [OpenNTF 的 RAG webinar 筆記](/domino-news/posts/openntf-domino-iq-rag-webinar)提到，Readers/Authors 欄位的安全模型是到 FP1 才真正到位——這是 webinar 上 Brian 的說法，FP1 官方說明並沒有逐條列這件事。）

至於 RAG 這條管線在 server 裡怎麼運作、那個 30 字元的欄位坑怎麼繞，那篇筆記與更早的技術拆解都寫過，這裡不重講。

## 修的比加的多：49 個修正與一次 JVM 更新

Fix Pack 的重點終究是修正。[panagenda 整理的客戶資訊](https://www.panagenda.com/blog/customer-information-for-hcl-notes-and-domino-14-5-1-fix-pack-1/)點出一個值得注意的事實：FP1 的修正裡，有相當比例是**修回 14.5.1 自己引入的 regression**。換句話說，如果你升到 14.5.1 之後才開始遇到某些以前沒有的怪象，先別急著怪自己的程式——FP1 很可能已經對症下藥。

幾個具體數字：

- **約 49 個修正**橫跨 Notes 與 Domino（官方 release notice 寫「約 46」、panagenda 的公開修正清單列到 49，數字有點出入），另有 **6 個** 內嵌 Sametime 的修正。
- JVM 更新到 **Semeru `jdk-21.0.11+10`**，時區資料版本 **2026b**。任何吃時區的邏輯——跨區排程、`NotesDateTime` 的換算——都跟著受惠。
- **2 個安全修正**：一是修復 OIDC 串接式（chained）Identity Provider 的設定；二是新增 `OIDC_LOGIN_COOKIE_UNLIMITED_DURATION`，讓你控制登入 cookie 要不要吃無限效期。

## 藏在 notes.ini 的幾個小調整

FP1 也塞了幾個開發者一眼就懂痛在哪的小開關：

- **tabbed table 的分頁顏色**：14.5.1 改了行為、有人不習慣，FP1 給了一個 notes.ini 設定調回 14.5.1 之前的樣子。
- **MIME 郵件的內嵌瀏覽器**：預設從 IE 換成 Edge，用一個 notes.ini 設定控制。老 IE 元件終於在這個角落退場。
- **JavaScript 編輯器**的反應速度也做了改善。

## 誰該升、怎麼升

官方的定調是「建議所有客戶安裝」，這在 Fix Pack 裡算是相對明確的措辭——通常代表修正涵蓋面廣、風險低。支援平台大致與 14.5.1 相同：Windows 10/11 與 Server 2019/2022/2025（64 位元）、macOS Sonoma／Sequoia／Tahoe；FP1 另外新增了 SUSE Linux Enterprise 15 SP6 的支援。

安裝方式就是一般的 Fix Pack 流程，疊在既有的 14.5.1 之上，不是整版重裝。若你手上還是更早的版本、還沒上 14.5.1，可以參考站上的 [Domino 2026 重點整理](/domino-news/posts/hcl-domino-2026-release-highlights)先補齊大版本的變化，再一路升到 FP1。

---

一句話總結：FP1 不是拿來看新功能的——RAG 的 Remote 模式是唯一亮點，其餘價值在「把 14.5.1 修穩」。如果你正卡在 14.5.1 的某個 regression，這就是你等的那一包；完整修正清單以官方的 FP1 說明頁為準。
