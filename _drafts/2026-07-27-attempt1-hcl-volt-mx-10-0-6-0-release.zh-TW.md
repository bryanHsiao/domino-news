HCL Volt MX 於 2026 年 4 月 22 日正式發布了 10.0.6.0 版本，為開發者帶來多項新功能與增強。以下是本次更新的主要亮點：

## 企業密鑰管理（EKM）

在 Volt Foundry 中引入了企業密鑰管理功能，提供更安全的憑證儲存解決方案。詳細資訊請參閱 [企業密鑰管理（EKM）](https://developer.ds.hcl-software.com/t/hcl-volt-mx-10-0-6-0-is-available/172524)。

## 伺服器推送事件（SSE）支援

新增對伺服器推送事件的支援，允許應用程式即時接收來自伺服器的更新，提升用戶體驗。

## SAML 驗證改進

在 Volt Foundry 中實現了基於 SAML 的驗證，支援在同一瀏覽器視窗內進行驗證 URL 重定向。

## OpenAPI 3.1 支援

增強了對 OpenAPI 3.1 的支援，允許生成和下載符合 OpenAPI 3.1 規範的 API 文件。

## 憑證驗證（CBA）

為 OAuth 2.0 適配器實現了憑證驗證，提供更安全的驗證方式。

## AWS SDK v2 支援

更新應用程式運行時，包含 AWS SDK v2，以支援從 SDK v1 的自訂代碼遷移。

更多詳細資訊，請參閱 [HCL Volt MX 10.0.6.0 發布公告](https://developer.ds.hcl-software.com/t/hcl-volt-mx-10-0-6-0-is-available/172524)。

開發者可透過 [HCL 軟體下載入口](https://developer.ds.hcl-software.com/t/hcl-volt-mx-10-0-6-0-is-available/172524) 取得安裝套件，並參閱 [官方發布說明](https://help.hcl-software.com/voltmx/v10/VMX_release_notes.html) 以了解更多資訊。
