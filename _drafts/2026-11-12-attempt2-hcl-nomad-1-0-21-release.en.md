HCL Nomad 1.0.21 was officially released on September 15, 2026, focusing on resolving several issues to improve application stability and user experience. ([support.hcl-software.com](https://support.hcl-software.com/csm?id=kb_article&sysparm_article=KB0090289&utm_source=openai))

## Key Fixes

- **Date/Time Field Multi-Selection Issue**: Resolved an issue where selecting multiple values in the "Date/Time" field was not possible under certain conditions. ([developer.ds.hcl-software.com](https://developer.ds.hcl-software.com/t/hcl-nomad-for-web-browsers-and-hcl-nomad-server-on-domino-1-0-21-are-now-live/172781?utm_source=openai))

- **IME Input Issue**: Fixed a problem where inputting text into a database field was not possible while the Search dialog was displayed. ([developer.ds.hcl-software.com](https://developer.ds.hcl-software.com/t/hcl-nomad-for-web-browsers-and-hcl-nomad-server-on-domino-1-0-21-are-now-live/172781?utm_source=openai))

- **Embedded Outline Icon Position Issue**: Corrected an issue where the "Middle-right" position for embedded outline icons was not honored. ([developer.ds.hcl-software.com](https://developer.ds.hcl-software.com/t/hcl-nomad-for-web-browsers-and-hcl-nomad-server-on-domino-1-0-21-are-now-live/172781?utm_source=openai))

- **Print Preview Issue**: Addressed a problem where the Print Preview dialog displayed extra input fields, and text and borders were misaligned. ([developer.ds.hcl-software.com](https://developer.ds.hcl-software.com/t/hcl-nomad-for-web-browsers-and-hcl-nomad-server-on-domino-1-0-21-are-now-live/172781?utm_source=openai))
