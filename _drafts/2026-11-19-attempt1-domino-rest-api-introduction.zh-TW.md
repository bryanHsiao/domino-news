## 什麼是 HCL Domino REST API？

HCL Domino REST API 提供了一個安全的 REST API，允許開發者以現代的方式存取 HCL Domino 伺服器和資料庫。這使得開發者可以使用自己偏好的程式語言，擴展和現代化 Domino 應用程式。 ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/topicguides/introducingrestapi.html?utm_source=openai))

## 主要功能

- **跨平台支援**：Domino REST API 可在 Windows、Linux 和 macOS 上運行，並支援 Docker 容器，提供靈活的部署選項。 ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/tutorial/installconfig/install/downloaddrapi.html?utm_source=openai))

- **安全性**：該 API 繼承了 Notes 和 Domino 的安全模型，使用 JSON Web Token（JWT）和範圍（Scopes）進行身份驗證，確保資料的安全存取。 ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/topicguides/understanding.html?utm_source=openai))

- **現代化的 API 設計**：基於 OpenAPI 3.0 規範，提供互動式的 API 文件，方便開發者理解和使用。 ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/references/openapidefinitions.html?utm_source=openai))

## 安裝與配置

1. **下載安裝檔案**：

   - 前往 [My HCLSoftware Portal](https://opensource.hcltechsw.com/Domino-rest-api/tutorial/installconfig/install/downloaddrapi.html) 下載適合您 Domino 版本的安裝檔案。

2. **安裝**：

   - 根據您的作業系統，按照官方文件中的步驟進行安裝。

3. **啟動 REST API**：

   - 在 Domino 伺服器控制台輸入 `load restapi`，啟動 REST API。

   - 若希望在伺服器啟動時自動啟動 REST API，請在 `notes.ini` 文件的 `ServerTasks` 條目中添加 `restapi`。 ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/references/usingdominorestapi/restapitask.html?utm_source=openai))

## 開始使用

1. **創建資料庫配置（Schema）**：

   - 使用管理界面或 API，為現有的 Domino 資料庫創建 Schema，定義可通過 API 存取的表單、視圖、文件夾、代理和文件項目。 ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/references/usingdominorestapi/index.html?utm_source=openai))

2. **啟用表單和視圖**：

   - 在 Schema 中啟用您希望通過 API 存取的表單和視圖。

3. **激活 Schema**：

   - 創建範圍（Scope），將其映射到您的 Schema，從而激活配置。

4. **測試 API**：

   - 使用如 `curl` 或 Postman 等工具，測試 API 的功能。

5. **配置應用程式**：

   - 在管理界面中配置應用程式，創建 `client_id` 和 `client_secret`，以便您的應用程式使用 OAuth 進行身份驗證。

HCL Domino REST API 為開發者提供了一個強大且安全的工具，允許他們使用現代的程式語言和框架，存取和操作 Domino 資料庫。通過遵循上述步驟，您可以快速安裝、配置並開始使用該 API，從而擴展和現代化您的 Domino 應用程式。 ([hcl-software.com](https://www.hcl-software.com/blog/domino/domino-administrators-what-you-need-to-know-about-the-domino-rest-api?utm_source=openai))
