HCL 於 2026 年 4 月 7 日發布了 Domino REST API 1.1.7 版本，為開發者和管理員帶來多項新功能和改進，進一步提升了應用程式開發和管理的效率。

## 主要新功能

- **新增功能**：
  - 引入了五項新功能，擴展了 API 的能力，滿足更廣泛的開發需求。

- **改進**：
  - 實施了六項改進，提升了系統的穩定性和性能。

- **問題修復**：
  - 解決了四個已知問題，增強了系統的可靠性。

詳細資訊請參閱 [HCL Domino REST API 的最新資訊](https://opensource.hcltechsw.com/Domino-rest-api/whatsnew/index.html)。

## 安裝與配置

Domino REST API 可在 Windows、Linux 和 Docker/Kubernetes 容器上的 Domino 12.0.2+ 伺服器上運行。安裝過程涉及下載安裝程式、配置伺服器任務以及設置相關的 Domino 資料庫。具體步驟和詳細資訊可參考 [Domino REST API 的安裝指南](https://opensource.hcltechsw.com/Domino-rest-api/tutorial/installconfig/install/downloaddrapi.html)。

## 管理與安全性考量

由於 Domino REST API 在 Domino 伺服器上運行，管理員需要確保其正確安裝、配置和監控。這包括設置安全的端口、管理訪問權限以及監控伺服器任務的狀態。更多資訊可參考 [Domino 管理員需要了解的 REST API 資訊](https://www.hcl-software.com/blog/domino/domino-administrators-what-you-need-to-know-about-the-domino-rest-api)。

## 進一步學習資源

為了更深入地了解 Domino REST API，建議觀看 OpenNTF 舉辦的網絡研討會，該研討會從管理員的角度介紹了該 API 的安裝、配置和管理。您可以在此觀看完整的研討會錄影：[Domino REST API 從管理員視角的研討會](https://www.youtube.com/watch?v=BLYySAYyjMQ)。

透過這些資源，開發者和管理員可以更好地利用 Domino REST API 1.1.7 版本，提升應用程式的開發效率和系統的管理能力。
