## Introduction

In HCL Domino development, handling XML data is a common requirement. LotusScript offers a suite of classes to facilitate XML processing, with `NotesXMLProcessor` serving as the foundational class for all XML processing classes. This article delves into the primary functions of `NotesXMLProcessor` and provides practical examples of its application in LotusScript.

## Overview of the NotesXMLProcessor Class

`NotesXMLProcessor` is an abstract base class encompassing properties and methods shared by all XML processing classes. Its derived classes include:

- `NotesDOMParser`: Parses XML into a DOM tree.
- `NotesDXLExporter`: Converts Domino data to DXL (Domino XML).
- `NotesDXLImporter`: Converts DXL back to Domino data.
- `NotesSAXParser`: Processes XML using the SAX (Simple API for XML) parser.
- `NotesXSLTransformer`: Transforms DXL data using XSLT.

It's important to note that `NotesXMLProcessor` itself cannot be instantiated directly. Instead, instances of its derived classes are created using the appropriate methods of the `NotesSession` class.

## Key Properties and Methods

### Properties

- `ExitOnFirstFatalError`: Boolean indicating whether processing should terminate upon encountering a fatal error.
- `Log`: Read-only property containing an XML representation of warnings, errors, and fatal errors generated by the processor.
- `LogComment`: Read-write property for adding a comment to the beginning of the log.

### Methods

- `SetInput`: Specifies the input for the XML process.
- `SetOutput`: Specifies the output for the XML process.
- `Process`: Initiates the XML data conversion or parsing.

## Example: Exporting a Domino Database to DXL

The following example demonstrates how to use `NotesDXLExporter` (a subclass of `NotesXMLProcessor`) to export the current database to a DXL file.

```lotusscript
Sub Initialize
    Dim session As New NotesSession
    Dim db As NotesDatabase
    Set db = session.CurrentDatabase

    ' Create output stream
    Dim stream As NotesStream
    Set stream = session.CreateStream
    Dim filename As String
    filename = "C:\dxl\" & Left(db.FileName, Len(db.FileName) - 3) & "xml"
    If Not stream.Open(filename) Then
        Messagebox "Cannot open " & filename,, "Error"
        Exit Sub
    End If
    Call stream.Truncate

    ' Create DXL exporter
    Dim exporter As NotesDXLExporter
    Set exporter = session.CreateDXLExporter
    Call exporter.SetInput(db)
    Call exporter.SetOutput(stream)

    ' Execute export
    Call exporter.Process

    ' Check log
    If exporter.Log <> "" Then
        Messagebox "Errors occurred during export: " & exporter.Log,, "Error"
    Else
        Messagebox "Export successful!",, "Success"
    End If
End Sub
```

In this example, we first create a `NotesStream` object as the output, then use the `CreateDXLExporter` method to create a `NotesDXLExporter` object. We set the input and output using the `SetInput` and `SetOutput` methods, respectively, and finally call the `Process` method to perform the export. After the export, we check the `Log` property to ensure no errors occurred.
