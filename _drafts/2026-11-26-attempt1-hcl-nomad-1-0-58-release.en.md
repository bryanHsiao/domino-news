HCL has recently released version 1.0.58 of HCL Nomad, bringing several new features and enhancements to improve the user experience of Domino applications on mobile devices.

## Document Printing Feature

Users can now print documents directly from HCL Nomad to any AirPrint-enabled printer or export them as PDFs via the iOS share sheet. To utilize this feature, simply long-press anywhere in a document window and select "Print...". This functionality also supports the `@Command([FilePrint])` formula command, though optional parameters are ignored. Administrators have the option to manage printing capabilities through new settings. For more details, refer to the [HCL Nomad User Documentation](https://help.hcl-software.com/nomad/1.0/hcln_welcome.html).

## App Shortcuts and Siri Integration

HCL Nomad now supports native app intents, allowing users to quickly open the application or replication page via shortcuts, Spotlight search, or Siri voice commands. For instance, users can say "Show the replication page in HCL Nomad" to trigger the corresponding action. Note that Siri voice commands require Siri AI support, which is currently limited to select locales. Administrators can manage this feature through new settings. More information is available in the [HCL Nomad User Documentation](https://help.hcl-software.com/nomad/1.0/hcln_welcome.html).

## Top-Tab Navigation on iPhone

On iPhone devices, application tabs have been relocated to the top of the screen, providing smoother navigation and tab switching. This improvement aims to enhance user convenience on smaller screens.

## Minimum iOS Version Requirement

Please note that HCL Nomad 1.0.58 now requires a minimum iOS version of 17.0, up from the previous requirement of 16.0. Ensure your device is updated to the latest iOS version to take advantage of these new features and improvements.

These updates are designed to enhance the functionality and user experience of HCL Nomad, enabling users to work more efficiently with Domino applications on their mobile devices.
