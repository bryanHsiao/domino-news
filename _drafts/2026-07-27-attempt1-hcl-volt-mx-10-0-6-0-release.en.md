HCL Volt MX officially released version 10.0.6.0 on April 22, 2026, bringing several new features and enhancements for developers. Here are the key highlights of this update:

## Enterprise Key Management (EKM)

Introduced in Volt Foundry, EKM provides a more secure solution for credential storage. For more details, see [Enterprise Key Management (EKM)](https://developer.ds.hcl-software.com/t/hcl-volt-mx-10-0-6-0-is-available/172524).

## Server-Sent Events (SSE) Support

Added support for Server-Sent Events, allowing applications to receive real-time updates from the server, enhancing user experience.

## SAML Authentication Improvements

Implemented SAML-based authentication in Volt Foundry to support authentication URL redirection within the same browser window.

## OpenAPI 3.1 Support

Enhanced support for OpenAPI 3.1, enabling the generation and download of OpenAPI 3.1–compliant API documentation.

## Certificate-Based Authentication (CBA)

Implemented Certificate-Based Authentication for the OAuth 2.0 adapter, providing a more secure authentication method.

## AWS SDK v2 Support

Updated application runtimes to include AWS SDK v2 to support custom code migration from SDK v1.

For more detailed information, refer to the [HCL Volt MX 10.0.6.0 Release Announcement](https://developer.ds.hcl-software.com/t/hcl-volt-mx-10-0-6-0-is-available/172524).

Developers can obtain the installation kits through the [HCL Software Download Portal](https://developer.ds.hcl-software.com/t/hcl-volt-mx-10-0-6-0-is-available/172524) and consult the [official release notes](https://help.hcl-software.com/voltmx/v10/VMX_release_notes.html) for more information.
