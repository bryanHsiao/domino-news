## Overview of Recent HCL Nomad iOS Updates

HCL Nomad enables users to access Domino applications directly from their mobile devices. Recent iOS versions have introduced several new features and improvements to enhance user experience.

### Version 1.0.56

- **Redesigned Replication Page**: The replication page has been updated for a cleaner design, making it more user-friendly on both phones and tablets.

- **Scheduled Replication**: Users can now configure replication schedules, choosing between every 15 minutes, every hour, or turning it off.

- **Improved Help Prompts**: Tapping the "?" help icon in preference dialogs now correctly displays hints and context text.

- **Updated App Icons**: The Nomad app icon on the home screen and icons within menus have been refreshed with a new look.

### Version 1.0.55

- **iPadOS 26 Support**: On iPads running iPadOS 26 and later, the Create and Actions menus are now available in the new system menu bar.

- **Extended Background Replication**: Active replication continues for up to 30 seconds after Nomad enters the background.

### Version 1.0.54

- **Bug Fixes**: Addressed various known issues to improve application stability.

### Version 1.0.53

- **Updated Dialog List Button**: The dialog list button features an updated icon and improved size.

- **Enhanced Open Application Dialog**: The "Up one level" button icon has been updated.

- **About Page Updates**: The version's year and month are now displayed alongside the product name.

- **Bug Fixes**: Resolved multiple known issues.

### Version 1.0.52

- **Rich Text Lite Field Refresh**: The Rich Text Lite field has been updated to utilize the HCL Enchanted design language.

- **New "Inter" Font**: The "Inter" font is now included and set as the default sans-serif font for most locales.

### Version 1.0.51

- **Updated Controls**: The following controls have been refreshed to utilize the HCL Enchanted design language: radio button, check box, list box, picker fields, text field delimiters, and tabbed table.

### Version 1.0.50

- **Support for iPadOS 26 Menu Bar and Window Controls**: Added support for iPadOS 26 menu bar and window controls.

These updates aim to enhance the functionality and user experience of the HCL Nomad iOS version. For more detailed information, refer to the [HCL Nomad iOS Release Notes](https://help.hcl-software.com/nomad/1.0/hcln_whatsnew.html?scLang=en).
