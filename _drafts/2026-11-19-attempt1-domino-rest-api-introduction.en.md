## What is HCL Domino REST API?

The HCL Domino REST API provides a secure REST interface, allowing developers to access HCL Domino servers and databases in a modern way. This enables developers to use their preferred programming languages to extend and modernize Domino applications. ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/topicguides/introducingrestapi.html?utm_source=openai))

## Key Features

- **Cross-Platform Support**: The Domino REST API runs on Windows, Linux, and macOS, and supports Docker containers, offering flexible deployment options. ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/tutorial/installconfig/install/downloaddrapi.html?utm_source=openai))

- **Security**: The API inherits the security model of Notes and Domino, utilizing JSON Web Token (JWT) and scopes for authentication, ensuring secure data access. ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/topicguides/understanding.html?utm_source=openai))

- **Modern API Design**: Based on OpenAPI 3.0 specifications, it provides interactive API documentation, facilitating developers' understanding and usage. ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/references/openapidefinitions.html?utm_source=openai))

## Installation and Configuration

1. **Download Installation Files**:

   - Visit the [My HCLSoftware Portal](https://opensource.hcltechsw.com/Domino-rest-api/tutorial/installconfig/install/downloaddrapi.html) to download the installation files suitable for your Domino version.

2. **Installation**:

   - Follow the official documentation steps for your operating system to install the API.

3. **Start the REST API**:

   - In the Domino server console, enter `load restapi` to start the REST API.

   - To ensure the REST API starts automatically with the server, add `restapi` to the `ServerTasks` entry in the `notes.ini` file. ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/references/usingdominorestapi/restapitask.html?utm_source=openai))

## Getting Started

1. **Create Database Configuration (Schema)**:

   - Use the admin UI or API to create a schema for an existing Domino database, defining the forms, views, folders, agents, and document items accessible through the API. ([opensource.hcltechsw.com](https://opensource.hcltechsw.com/Domino-rest-api/references/usingdominorestapi/index.html?utm_source=openai))

2. **Enable Forms and Views**:

   - Within the schema, enable the forms and views you wish to access via the API.

3. **Activate the Schema**:

   - Create a scope mapping to your schema to activate the configuration.

4. **Test the API**:

   - Use tools like `curl` or Postman to test the API's functionality.

5. **Configure Applications**:

   - In the admin UI, configure applications by creating `client_id` and `client_secret` credentials for OAuth authentication.

## Conclusion

The HCL Domino REST API offers developers a powerful and secure tool to access and manipulate Domino databases using modern programming languages and frameworks. By following the steps outlined above, you can quickly install, configure, and begin using the API to extend and modernize your Domino applications.
