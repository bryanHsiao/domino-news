On April 7, 2026, HCL released version 1.1.7 of the Domino REST API, bringing several new features and improvements aimed at enhancing application development and management.

## Key Features

- **New Additions**:
  - Five new features have been introduced, expanding the API's capabilities to meet a broader range of development needs.

- **Improvements**:
  - Six enhancements have been implemented to improve system stability and performance.

- **Issue Resolutions**:
  - Four known issues have been addressed, enhancing system reliability.

For detailed information, refer to the [What's New in HCL Domino REST API](https://opensource.hcltechsw.com/Domino-rest-api/whatsnew/index.html).

## Installation and Configuration

The Domino REST API can be deployed on Domino 12.0.2+ servers running on Windows, Linux, and Docker/Kubernetes containers. The installation process involves downloading the installer, configuring server tasks, and setting up related Domino databases. Detailed steps and information can be found in the [Domino REST API Installation Guide](https://opensource.hcltechsw.com/Domino-rest-api/tutorial/installconfig/install/downloaddrapi.html).

## Administration and Security Considerations

Since the Domino REST API operates on the Domino server, administrators must ensure its proper installation, configuration, and monitoring. This includes setting secure ports, managing access permissions, and monitoring server task status. More information is available in the article [Domino Administrators - What You Need to Know About the Domino REST API](https://www.hcl-software.com/blog/domino/domino-administrators-what-you-need-to-know-about-the-domino-rest-api).
